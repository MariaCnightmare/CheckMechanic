# Consent / Opt-in / Delete（仕様案）

## 同意の原則
- 初期状態はOFF（未同意）
- 送信前に「送信項目一覧」をユーザーに提示
- 同意はいつでも撤回でき、削除要求も可能

## データレベル
- Basic（ランキング参加）: 最小限のみ
- Detailed（分析協力）: 追加項目（ただし個体識別になりやすい値は禁止）

## 削除
- 端末でランダムトークン（32bytes）を生成してローカル保存
- サーバには token_hash_sha256 のみ送る
- ユーザーがトークン提示 -> サーバでhash照合して削除

## UI文言（たたき台）
- 目的: 「ランキングの提供」「品質改善」「不具合解析」
- 送信しないもの: 「ホスト名・MACアドレス・シリアル番号など個体識別につながる情報は収集しません」
- 撤回: 「いつでも送信を停止できます」
- 削除: 「削除トークンを用いて、保存されたデータの削除を要求できます」
