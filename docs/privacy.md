# Privacy（草案）

本アプリは、ユーザーの同意（オプトイン）がある場合に限り、ランキング/比較指標の提供および品質改善のために
一部のシステム情報・ベンチマーク結果・要約テレメトリを送信します。

## 収集する可能性がある情報（Basic）
- OS種別とメジャーバージョン
- CPU/GPU/RAM/ストレージの「カテゴリ化された」情報
- ベンチマーク結果（複数回の中央値）
- 温度/負荷等の要約値（最大/95パーセンタイル等）

## 収集しない情報
- ホスト名、ユーザー名
- IPアドレス、MACアドレス、Wi-Fi SSID/BSSID
- シリアル番号、UUID、Windows Product ID
- 位置情報

## 利用目的
- カテゴリ別ランキングや比較の提供
- アプリ品質改善（性能・安定性・互換性）

## オプトアウト / 削除
- 設定から送信を停止できます
- 削除トークンにより、保存データの削除を要求できます

※本ドキュメントはPoC用の草案であり、公開前に法務/運用観点で整備します。
