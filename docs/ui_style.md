# UI Style Guide (Desktop)

## Spacing
- Root padding: `24`
- Card gap: `16`
- Card inner padding: `16` (KPI can use `20`)

## Radius
- Standard card radius: `16`
- Badge/button radius: `8` to `20` (pill for status only)

## Typography
- App title: `30px`, semibold
- KPI value: `24-36px`, semibold
- KPI label: `12px`, muted
- Helper text/subtext: `12px`, muted

## Colors
- Base: dark surface (`BackgroundBrush`, `SurfaceBrush`, `Surface2Brush`)
- Accent: teal (`AccentBrush`) as primary emphasis only
- Semantic: `WarningBrush`, `DangerBrush`, `SuccessBrush` for status/alerts only

## Button Rules
- Primary: single accent action (`再チェック`)
- Secondary: neutral action (`Core Temp 起動/前面`)
- Other actions: overflow menu (`…`)
- Hover/press feedback: border emphasis + subtle glow, no excessive neon effect
