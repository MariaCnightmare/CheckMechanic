# Threat Model（最小版）

## 想定する脅威
1. 再同定（レア構成・時系列ログ・詳細バージョン等）
2. 不正投稿（スコア捏造）
3. データ漏洩（保存領域/ログ/転送経路）
4. 同意なき収集（UI不備・既定ON）

## 対策（v1）
- データ最小化（個体識別値は収集禁止）
- 公開は集計中心 + kしきい値（人数不足は非表示）
- ログに生データを出さない
- 同意は既定OFF、送信前に項目プレビュー
- 送信の完全停止・削除導線

## 対策（v2）
- 差分プライバシー（DP）で公開統計の安全性を強化
- 不正検知（外れ値、連続投稿、署名/Attestation等）
